## 图片交付候选（尚未实施）

### A. 现有 fzzapi 代理

本地同步获取元数据，HTML 固化代理图片 URL；部署不需要 Key。组件目前已支持此路径。
优点：少维护一个存储系统。风险：图片可用性取决于代理及上游，不等于自有归档。

### B. Cloudflare R2 + 自定义域名

R2 是对象存储，自定义域名接入 Cloudflare Cache；不应将 r2.dev 开发地址当生产 CDN。
只同步获准存储和公开展示的图片。上传凭据仅本机、最小桶权限，浏览器仅接收公开图片 URL。
建议对象名使用类型/媒体ID/内容哈希，分别存 poster 和 backdrop；明确 Content-Type 和版本化 Cache-Control。
本地预生成适当尺寸，R2 本身不负责自动缩图。公开图片不能同时含有私有快照或凭据。
上传后逐项验证 HTTP、MIME 与实际解码，全部通过才原子替换快照；保留旧快照和本地图片直到 Preview 验收结束。
CDN 冷缓存仍会读取 R2；存储及请求计费、其他 Cloudflare 服务可能另收费，不能将免出口流量等同完全免费。

建议先用少量已获授权图片做 R2 试验，不批量上传当前所有海报。存储迁移不能解决缺失素材来源，也不能替代 TMDB 元数据授权。

官方参考：

- https://developers.cloudflare.com/r2/buckets/public-buckets/
- https://developers.cloudflare.com/r2/pricing/
